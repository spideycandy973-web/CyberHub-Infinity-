# Game Design Bible

Setting: megacity KAGEROU-9, 2147, run by Halcyon Dynamics, which sells "Afterglow" memory storage. Tiers: Skyline Tier, Midcity, Underflow.

Districts and palettes:
- Halcyon Heights: #E8F1FF, #FFD27A, #4A6CFF
- Lantern Market: #FF2E88, #00E5FF, #FFB300
- Rustline: #FF6A00, #5B6B7A, #1B1F2A
- Underflow: #00FFC8, #7A3CFF, #0A1020
- Skyline Gardens: #9DFF8A, #FFFFFF, #FF8FD0

Protagonist: Rin Hoshizora, 17-19, memory courier. ~7 heads tall. Indigo bob with cyan tips and a white hairpin. Amber eyes. Teal-and-black cropped jacket with glowing cyan seams. Shorts, utility belt, emissive-sole boots. Left fingerless glove. Right wrist module "Echo".
Companion: Pip, a floating drone.
Cast: Kaito Hoshizora (missing older sibling), Mama Sora, Vex (rival), Dr. Ayame Voss, Director Tsukuyomi (antagonist), the Lanternkeepers.

Story: Prologue "Last Delivery"; Act 1 "Echoes"; Act 2 "Sinking Light"; Act 3 "Afterglow" (v2, not started).
Missions: courier, investigation, race, stealth-lite, hover-bike.
Collectibles: Memory Fragments and Echo Shards, with non-combat upgrades.
All names are original.
